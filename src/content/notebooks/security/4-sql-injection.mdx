usually holds everything.

```text
  login form                         what it becomes

  email:  ' OR '1'='1' --            WHERE email = '' OR '1'='1' --'
  password: anything                 ──▶ returns the first user in the table
                                     ──▶ your code compares nothing, or
                                         logs them in as whoever that is
```
