The endpoint wants a user with their profile embedded. Two round trips is the
naive answer; one is available.

```sql
SELECT u.*,
       to_jsonb(up.*) AS profile
FROM users u
LEFT JOIN user_profiles up ON up.user_id = u.id
ORDER BY u.created_at DESC;
```
